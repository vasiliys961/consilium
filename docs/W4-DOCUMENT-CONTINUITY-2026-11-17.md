17 November 2026. Independent branch `codex/w4-document-continuity`, based on
`chatgpt-dev` commit `9443e67`. This branch does not contain the unmerged changes
in #75/#76/#83/#84/#85/#86. No merge, deployment, paid API call or patient data.

## Physician outcome

The document selected in the case opens in its own editor with the exact ID and
language. Structured documents use the existing short editor; native RU/Global
notes keep their own original applications. A missing or wrong-language ID never
silently falls back to another saved note. Protocol kinds now use clinical labels
instead of the internal `encounter` key.

The short editor keeps unsaved source text and document edits as separate local
case drafts, keyed by language, layout, analysis source and selected note. Leaving
via its links, switching context and locking the vault flush pending work first.
Storage failures keep the current editor open and offer DOCX rescue. Unlinked
standalone work still requires confirmation before discarding it. No new editor
or model is introduced.

Explicit save re-reads the case inside its existing write queue, updates protocol
fields only, and retains previous versions when the same note is edited. Other
case facts, source files, clinical analyses and physician decisions are preserved.
Saving clears only the matching draft. Closed/missing cases and language/edition
identity collisions are rejected. Drafts also appear as unfinished work in the
Markdown rescue export, separately from saved notes.

Original printable notes now include the already-present ECG evidence, council
opinions and dissent, missing-role limitations, all physician decisions and
sources. No network score becomes a diagnosis. Clinical source text is no longer
silently cut off after 100,000 characters; existing explicit export/request limits
still apply. No clinical content is translated or regenerated by printing.

## Reproduction

Generate the disposable encrypted fixture without network requests:

```
node --require ./scripts/openrouter-only.cjs --experimental-strip-types scripts/create-synthetic-document-case.ts /private/tmp/synthetic-document-case.doctor-opus-case
```

The script prints its fixed synthetic fixture password. It is not a user credential.
Import via Workspace → restore single case; follow the acceptance sequence above.
Use an isolated test origin. Do not overwrite an existing real case.
