# Radiology, самостоятельные помощники и протоколы — 12 ноября 2026

## Выполнено

- Radiology: внутренние меню, руководство, техническая панель, описания установки и динамические сообщения включены в языковые каталоги. Переведены недостающие строки всех 10 языков; локальные копии каталогов доступны каждой странице. Язык передаётся при переходах и загружается на сервере до первого отображения. SessionStorage содержит только непрозрачный токен связи, без клинического контекста.
- Развёрнутый просмотр: изображение занимает всю ширину, боковая колонка находится ниже. В интеграции iframe может занять окно целиком; доступны возврат кнопкой и Esc. Проверено на синтетическом PNG: ширина изображения 1248 при окне 1280, sidebarTop > stageBottom. DICOM сохраняет ResizeObserver для перерасчёта canvas. Детекторы и обработка медицинских изображений не изменялись.
- `/scanner`: самостоятельный сканер и приём файлов с телефона по QR без случая. Отдельный токен приёма не смешивается с QR клинического случая. PDF, фото, видео и файлы сохраняются в отдельной браузерной папке приёма; есть скачивание, сохранение в выбранную папку через File System Access API, корзина и восстановление. В Safari используется обычное скачивание. До 8 МБ на файл; оригиналы не уходят моделям и не попадают в случай автоматически. Это хранилище не входит в зашифрованный архив случаев.
- `/drug-checker`: самостоятельная проверка текущих препаратов и предполагаемого назначения, отдельные уточнения, локальные правила, модельный разбор с источниками и выбранными FDA/DailyMed-инструкциями. Есть копирование списка и переход в Drugs.com. Это внешний сайт, результаты оттуда автоматически не извлекаются. RxNav Interaction API не используется: NLM прекратила его 2 января 2024.
- Поиск FDA принимает многоязычные названия и фармацевтическую латынь. Сначала проверяются известные соответствия, затем при необходимости предлагается английское название через модель и проверяется реальным FDA-поиском. Разрешённое имя показывается врачу; конкретную инструкцию и форму выбирает врач. Реальная проверка: Warfarini → warfarin (6 инструкций), 二甲双胍 → metformin (5 инструкций), ссылки DailyMed действительные по структуре ответов API.
- Протоколы: устранено раннее завершение переключения EN, когда общий интерфейс уже EN, а внутри ещё RU. Завершившийся процесс больше не считается работающим после сигнала. Обе версии увеличили шрифт полей до 18 px, текст документа до 18 px.
- Промпты сопоставлены с материнскими шаблонами. Убраны универсальные back-pain/red-flag списки для всех специальностей, противоречивое требование выдумывать нормальный осмотр и общий запрет всех численных дозировок. Сохранены структура специальности, факты случая, конкретный план, различие сделанного и предложенного, однократные предметные уточнения. Общая фактическая инструкция RU/EN согласована. Для остальных языков основа — английский промпт; SOAP-заголовки переводятся, проверка принимает локализованные заголовки.

## Проверки и ограничения

Основной набор: 265 тестов (включая хранение/дедупликацию/корзину приёма, языковые каталоги Radiology, сохранение токена при переходах, переключение версии протокола при уже выбранном EN, локализованный SOAP, латинские названия FDA). Production-сборки основного приложения и обеих версий протокола прошли. Итоговый набор основного приложения: 265/265.

Radiology: TypeScript и production build проходят. Полный унаследованный набор дал 698/712: 14 проверок читают и сопоставляют точное форматирование других исходных компонентов (`UnifiedDicomStudyAnalysis`, `DetectorGeminiOpusConsilium`, `ClinicalDicomVisionPlan` и др.). Эти компоненты не менялись в этой задаче. Проверки не отключались; их результат не считается клинической валидацией.

Физический iPhone, внешний УЗИ-видеовход и большая реальная библиотека исследований не проверялись. Пользователь отложил видеовход: его код не менялся. Возможность прямого захвата зависит от видеовыхода аппарата и совместимого устройства захвата; текущий модуль использует браузерный видеовход или захват окна и добавляет выбранные кадры, не анализирует весь поток непрерывно.

При браузерной проверке дополнительно устранена перезагрузка iframe при смене языка внутри Global: новый язык передаётся сообщением, текущий текст остаётся в том же редакторе. Шрифт полей закреплён на реальном div-контейнере, а не только на main.

## Итоговая браузерная проверка

- Английский протокол действительно отображается внутри Concilium, включая редактор и шаблоны. Измеренный размер поля: 18 px. EN → FR изменяет внутренний интерфейс без изменения src/session iframe, то есть без перезагрузки редактора.
- Во французской версии лекарственного модуля проверены внутренние подсказки и локальное предупреждение для тестового сочетания warfarin + ibuprofen; ссылка DailyMed присутствует. Модельный разбор этой тестовой пары дополнительно не запускался.
- Интегрированный Radiology в развёрнутом режиме имеет iframe 1280×720 при окне 1280×720. Esc возвращает iframe из fixed в обычный поток. Ранее на синтетическом PNG подтверждено положение боковой колонки ниже изображения.
- Автономный сканер показал действующий QR с purpose=inbox. Тестовый файл через API телефона получил HTTP 200 и появился в браузерной папке приёма, без выбора случая. После перезапуска файл сохранился. Физический смартфон этот тест не заменяет.

Видеовход не менялся. Дорожная карта дополнена его явным отложенным статусом.

### Argon вместо Gemini 3.1 Pro · 13 ноября
- В основном контуре разбора и общем Gemini-шлюзе модель Pro заменена на `google/gemini-4-argon`. Врач может выбрать `google/gemini-3.8-flash`; настройка хранится в HttpOnly cookie этого браузера и передаётся в запросы разбора, включая потоковый режим. Начатые запросы сохраняют выбранную модель.
- С 1 декабря 2026 UTC включается пересмотр цены: сервер читает каталоги настроенных Polza/OpenRouter, сравнивает с зафиксированным ноябрьским тарифом и при подорожании предлагает выбор. Кэш цен — до 6 часов, с обязательным сбросом на границе 1 декабря; при недоступном каталоге требуется явный выбор, прежняя цена не выдаётся за проверенную. Значимые новые тарифные уровни требуют нового выбора; мелкие курсовые изменения RUB не сбрасывают подтверждение постоянно.
- Формулировка выбора: «Для сложных диагностических случаев рекомендуем оставить Argon». Основание — наш небольшой сравнительный тест; универсальная клиническая точность не заявляется. В окне есть актуальные тарифы и ссылка на полный локальный отчёт `/model-comparison`. Принудительного автоматического перехода на Flash нет.
- Оценка расходов обновлена для Flash 3.8 и Argon с учётом объявленного удвоения стандартного тарифа Google с 1 декабря. Живые тарифы Polza в RUB и OpenRouter в USD показываются раздельно; оценка в ленте не подменяет квитанцию провайдера.
- Новые подписи переведены на все языки основного интерфейса. Проверки покрывают границу даты, недоступность каталога, рост только выходного тарифа, сохранённый выбор, новый тарифный уровень, правильную передачу Flash/Argon провайдеру и дедупликацию проверки цены.
- Проверено в работающем браузере: выбор Flash сохраняется после перезагрузки; затем восстановлена Argon. Исправлена проверка Origin при локальном адресе 127.0.0.1 (Next реконструирует request.url через localhost). Итоговая сборка прошла; 273/273 тестов прошли. При одновременной сборке один существующий тест жёсткого таймера 100 мс сработал нестабильно под нагрузкой; отдельная проверка и последующий полный запуск прошли без изменений этого теста.

### Связь случая, станции и модулей · 13 ноября
- Новый случай сохраняется до первого разбора; `?new=1` заменяется постоянным `?case=UUID`. Добавлены автосохранение клинического черновика, сохранение незаданных вопросов/редактора и сериализация записей одного случая. Переходы в инструменты предварительно сохраняют черновик и передают его ID.
- Станция восстанавливает контекст и материалы выбранного случая. Из станции и радиомодуля можно создать случай, в том числе до первого анализа. Для выбранного случая станция автоматически сохраняет материалы; заключение сохраняется отдельным действием.
- DICOM и поддерживаемые архивы в станции направляются во встроенный настоящий Opus Radiology. Исходники передаются локально через ограниченный мост с проверкой origin/source/session и привязкой к исходным материалам. Повторяющиеся файлы архива и отдельные срезы дедуплицируются по SHA-256. Ограничения просмотрщика и детекторов не увеличены.
- Принятые радиомодулем исходники сохраняются внутри записи случая (и существующего шифрования хранилища). До 64 МБ исходников на передачу; для больших серий есть явное сообщение о сохранении только описания в случай и необходимости хранить оригиналы на диске.
- Заключения радиомодуля имеют отдельные записи с привязкой к исходникам, доступны в случае и включаются в контекст дальнейшего разбора. Уже разобранные в модуле файлы не отправляются повторно в общий LLM-путь как одиночный кадр. Непроработанный DICOM направляет врача в модуль до общего разбора.
- Цифровая ЭКГ в обоих входах использует общий ECGFounder; CSV распознаётся по содержимому, не только расширению. Для рентгеновской фотографии в станции врач может выбрать профиль, чтобы открыть радиомодуль. Автоматический профиль не заявлен как универсальная классификация произвольного изображения.
- Для ЭКГ сокращён промпт заключения, устранены указания, провоцировавшие повторы «не измерено / предложение ручной проверки» по каждому интервалу. Оценки по сетке группируются один раз с методом; подтверждённые измерения сохраняют статус. Указано согласовывать категорию ритма с имеющейся ЧСС и не выдумывать амплитуду в мм. Сначала показано заключение; описание и измерения раскрываются отдельно.
- Инструкция доступна в интерфейсе «Как связаны случай, станция и модули» и в docs/CASE-MODULES-GUIDE.md. Новые подписи переведены на языки основного интерфейса.
- Браузерная проверка: новый случай без ручного сохранения сохранил контекст и ID при переходе в Radiology и обратно; синтетический DICOM автоматически открылся в настоящем Cornerstone-просмотрщике (1 серия, 1 кадр, без пропусков). Техническая запись без клинических утверждений сохранена в тот же случай. Станция восстановила этот случай и исходный файл; создание нового случая из её материалов и локальное направление DICOM во встроенный радиомодуль проверены. Модельные диагностические вызовы в этой проверке не запускались.
- Основные тесты: 277/277; ограничения просмотрщика и проекций: 9/9. Основная и радиологическая production-сборки прошли. Для радиомодуля использован штатный `--webpack`: Turbopack ошибся на символьных ссылках `node_modules`. Существующие ограничения исходной тестовой батареи Radiology не объявляются устранёнными этими проверками.
- Заключительное повторное нажатие «Разобрать случай» не выполнено: автоматическая проверка отклонила действие из-за потенциального платного вызова. Повторного обходного запуска не делалось. До отказа локальная маршрутизация DICOM во встроенный модуль уже наблюдалась в браузере; снимок /private/tmp/concilium-case-station-linked.png. Функциональный перенос проверялся техническим текстом, не выдуманным результатом модели; клиническая точность ЭКГ по одному присланному тексту не оценивалась.
