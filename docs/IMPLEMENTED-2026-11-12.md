## Что уже проверялось

- Последний сохранённый отчёт основной тестовой команды: **256 тестов пройдены**, производственная сборка успешна. При обновлении этой документации команды заново не запускались: программный код не менялся.
- В браузере на синтетическом случае: несколько ответов и резюме, перенос проекта решения, завершение с текстом редактора, скачивание DOCX, возврат в работу, правка с историей, корзина и восстановление.
- Реальный синтетический запрос к пяти ролям консилиума завершил все роли, включая итог; длинные мнения больше не обрезаются локальным пределом 700 символов.
- PDF сканера с двумя страницами прошёл локальный рендер и OCR; клинические строки сохранились, тестовое имя и дата были удалены из подготовленного текста, исходный PDF в отправляемую копию не вошёл.
- В браузере проверены создание страницы сканера, непрерывный штрих кисти и отмена. Телефонная передача проверена через локальную сеть, с продлением сессии и запретом врачебного API на входе передачи файлов.
- **Не закрыты этими проверками:** работа на физическом iPhone/Android, клиническая точность на врачебном наборе случаев, полнота всех специализированных форматов и самостоятельное удалённое развёртывание. Эти пробелы находятся в плане.

Архитектурные сведения и результаты на 8 ноября остаются в [историческом отчёте интеграции](MATERNAL-INTEGRATION.md); его старые числа тестов и ограничения не являются текущей дорожной картой.

## Личная библиотека (последующее поручение)

Перенесена материнская браузерная база и локальная векторизация. Добавлены `/library`, импорт PDF/TXT/MD, папка компьютера через File System Access API с резервным импортом копий, оригиналы, продолжение смыслового индекса, автоматические предложения страниц по вопросу врача и явный выбор фрагментов. Страницы и идентификаторы источников проходят privacy-review и сохраняются в цитатах ленты. Подсказка о возможности библиотеки видна в окне разбора; есть ссылка в меню и карточка модуля. Поиск многоязычный, подписи поиска включены в языки приложения. Подробности и незавершённое — в [LIBRARY-PLAN.md](LIBRARY-PLAN.md).

Проверка: 259 тестов, TypeScript, production build; импорт и векторизация синтетического двухстраничного PDF проверены в браузере. Большая реальная библиотека и различия доступа к папкам в Chrome/Safari требуют отдельного прогона.

## Автоматический RAG и поиск иллюстраций · 13 ноября 2026

Автоматический подбор включён по умолчанию в библиотеке и случае. Вопрос → локальный гибридный поиск текста/изображений → ограниченный пакет источников → существующая проверка отправки → один запрос ответа OpenRouter. Страницы служат проверяемыми ссылками, ручной выбор необязателен. Добавлены структурные подписи/таблицы/сноски, координаты встроенных PDF-изображений и перекрывающиеся области для векторных иллюстраций, сохраняемый визуальный индекс CLIP с полным постраничным покрытием. Локальные веса CLIP установлены (61,5 МБ текстовая и 85 МБ визуальная часть). Изображения литературы отделены от изображений пациента.

Полный порядок работы и технические пределы: [LIBRARY-WORKFLOW.md](LIBRARY-WORKFLOW.md). Основные проверки модели ответа используют подменённый провайдер без платного вызова. Локальная визуальная индексация дополнительно проверяется в браузере.

Проверка автоматического RAG завершена: 292/292 тестов, успешная production-сборка, реальный локальный индекс 2/2 страниц и автоматический RU→EN подбор в браузере без платной генерации. Подробные границы и результаты: [qa/LIBRARY-AUTO-RAG-2026-11-13.md](qa/LIBRARY-AUTO-RAG-2026-11-13.md).
