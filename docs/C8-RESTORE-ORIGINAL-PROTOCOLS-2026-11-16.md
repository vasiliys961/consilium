# C8 — восстановление исходных протоколов и модуля рекомендаций

Дата: 16 ноября 2026. Причина: врач проверил C7 на Preview 3207; поиск слова «плеврит» не сформировал рекомендации, рецептурный бланк фактически требовал ручного ввода и протокол не достигал качества печатного заключения.

## Что отменено и что оставлено

1. **`/protocol` вновь указывает на `/protocol/case`**, как в исходном `main` Codex. **Оригинальные RU и EN приложения НЕ менялись**: исходный код `integrations/protocol/ru` и `integrations/protocol/en`, их собственные интерфейсы, промпты и встроенные рецепты, проверки взаимодействий, DOCX и многоязычные SOAP сохранены без исправлений и украшательства.
2. Для Preview нужен локальный набор node_modules для каждой дочерней копии. Новый `npm run dev:preview` однократно устанавливает npm-зависимости через lockfile **внутри** `integrations/protocol/ru` и `integrations/protocol/en`, затем запускает только родительский Preview на 3207. Исходные Desktop-приложения, их настройки и ключи не затрагивает. Сам родитель по требованию запускает дочерние приложения на **3211** (RU) и **3212** (EN). Главный Codex на 3107 и его приложения 3111/3112 остаются нетронутыми.
3. C7-замена `/prescriptions` удалена вместе с неудачным ручным бланком. Печатные рецептурные формы остаются внутри исходного русского модуля. C7-замена `/api/guidelines`, требовавшая от **первичного тематического поиска** громоздкого структурированного JSON-клинического разбора, удалена.
4. `/guidelines` — отдельный тематический поиск в стиле материнского `doctor-opus/app/protocols/page.tsx` и `app/api/protocols/search/route.ts`, с умеренной адаптацией под интерфейс Consilium. Вводится **одно слово/диагноз** (например, «плеврит»), необязательно специальность; контекст пациента и обязательный выбор случая отсутствуют. Возвращается форматированный текст: рекомендации, дифференциальная диагностика, критерии, обследования, лечение, мониторинг и источники.
5. Модельные режимы: **Кратко** — Gemini 3.8 Flash; **Стандарт** — Gemini 3.8 Flash; **Подробно** — Claude Sonnet 5.5; **Актуальные** — Perplexity Sonar через OpenRouter. Система не подменяет ответ бесплатным фрагментом JSON; отсутствие ответа провайдера показывается как ошибка, а не «рекомендаций нет». Добавлены редактирование, DOCX, системная печать/PDF, копирование для разбора и отправка **по действию врача**. Все вызовы требуют существующей проверки приватности.
6. **Оставлено на `/protocol/structured`**: после сохранённого полноценного разбора можно получить оригинальный текст без новых API-вызовов, связное заключение или формальный протокол через Flash; в самостоятельном встроенном режиме — GPT-6.1 Sol, с возможностью переоформить сохранённый результат через Flash. Пользователь просит **не смешивать** этот маршрут с самостоятельными RU/EN модулями. Пост-аналитическое предложение в клиническом случае направляет именно сюда.
7. Клинический разбор Consilium продолжает предлагать обследования и лечение; редактирует врач. Ничего не считается назначенным или выполненным без подтверждения.

## Следующие проверки

- CI: TypeScript, тесты, Next.js build. Не равно живому браузерному тестированию.
- Mac Preview: после `npm run dev:preview` открыть `/protocol`; выбор **RU** должен запустить неизменённое коричневое самостоятельное приложение на 3211, **EN** — исходное многоязычное приложение на 3212. У обоих убедиться в доступности их нативных функций без переноса в новый интерфейс.
- В `/guidelines` поочерёдно проверить слово «плеврит» в режиме Flash и Sonar на тестовом запросе (платные вызовы проводить только после разрешения врача); оценить качество и актуальность ссылок.
- Из сохранённого обезличенного случая проверить `/protocol/structured` отдельно: форматирование Sol/Flash и честный перенос данных без фиктивного осмотра.
- Не выполнять merge в main, не изменять Codex 3107, не модифицировать источники на Desktop. Если установка зависимостей не завершилась, лог npm покажет причину.

## Статус

Проверка CI и реальная проверка на компьютере ведутся раздельно. Никакие модельные запросы из ChatGPT во время этих изменений не оплачивались.
