# C7 — привязка клинического тезиса к содержанию источника

Дата: 16 ноября 2026. Ветка: `chatgpt/c7-source-applicability-20261116`.

## Что изменилось для врача

- В ленте источников связь с конкретным тезисом отображается рядом с **тем местом источника**, ключ которого указан в клиническом черновике. Разные абзацы одной публикации не теряются при группировке по заголовку.
- Указывается фактически доступный уровень материала: абзац полного текста, иной фрагмент, только аннотация или библиографическая запись. Доступная глава/страница/издание сохраняются.
- Для тезиса и вариантов лечения локально проверяется тематическое пересечение терминов. Несовпадающие числовые величины с единицами и явно упомянутые, но не обнаруженные в доступном тексте условия (беременность, возрастная популяция, почки/печень) отдельно отмечаются **для проверки врачом**.
- Библиографическая запись без содержания не повышается до уровня доказательства. Ссылка на источник не называется подтверждением.
- Поскольку интерфейс показывает то, что доступно в данных, существующие клинические ответы и назначения не блокируются из-за отсутствующей публикации. Никаких дополнительных сетевых вызовов, моделей, серверов или данных пациентов.

## Что эта проверка НЕ устанавливает

Тематическое сходство — не семантическая проверка медицинского утверждения и не оценка достоверности. Совпадение дозы с текстом не означает правильного показания, лекарственной формы, возраста, дозы или безопасности. Различие языка тезиса и источника может дать ложное отсутствие совпадения. Отсутствие упоминания в одном фрагменте не означает отсутствия условия в полном руководстве. Нет автоматической оценки GRADE, качества исследования, страны пациента, последней версии документа или полноты всех разделов. Никаких независимых клинических тестов не выполнялось.

## Проверки

Синтетические unit-тесты: библиографическая запись/аннотация/полный абзац, дозы и популяции, русский и английский язык, несколько разных абзацев и связей одной публикации. Проверку TypeScript, всего набора тестов и production-сборки должен подтвердить GitHub Actions для HEAD PR, затем post-merge CI.

## Оставшаяся работа C7

1. Добавить управляемое извлечение нескольких релевантных разделов полного текста, без ложного предположения о доступе к закрытым материалам.
2. Поддержать структурированные критерии применимости (показание, PICO-популяция, версия, раздел, уровень рекомендации), когда они реально распознаны в тексте. Нужна проверка точности извлечения.
3. По важным терапевтическим утверждениям тестировать семантическое соответствие утверждения месту источника и явное противоречие, а не только пересечение слов. Не доверять одной LLM как независимому подтверждению.
4. После обновления Preview провести врачебную и браузерную приёмку; не путать техническую интеграцию с клинической валидацией.
