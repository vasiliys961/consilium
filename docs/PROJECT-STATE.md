## Непересматриваемые условия без решения владельца
1. Сохранить действующую локальную установку и любые незакоммиченные изменения Codex.
2. Секреты, изображения пациентов, истории болезней и PHI не помещать в публичный репозиторий, CI или облачные preview.
3. Все LLM-вызовы — OpenRouter-only, как требует действующий `AGENTS.md`; тесты по умолчанию без сетевых вызовов к платным LLM.
4. Врачебный сценарий и безопасность важнее косметических переделок UI.
5. Не объединять PR и не выполнять деплой без явного одобрения.
