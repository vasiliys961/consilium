## Реальное функциональное состояние

- C3: 26 ограниченных локальных правил взаимодействий с метаданными DailyMed. Текущие/предлагаемые/отменяемые/альтернативные препараты и явно размеченный контекст (СКФ, калий, QTc, возраст, кровотечение, печень). Дополнительный прогон **500 синтетических вариантов**, стоимость медицинских API $0. **Не универсальная база, не клиническая валидация.**
- C4: передача смартфон → компьютер с идемпотентной загрузкой, подтверждением сохранения в приёмник и восстановлением проверки после краткого обрыва сети. Сессия ретранслятора в памяти; реальный iPhone/Android и HTTPS не проверены.
- C5: проверка количества/порядка страниц PDF встроенного сканера, запрет выдачи неполного OCR как полного документа. Важные лабораторные значения/дозы/отрицания отмечаются для сверки, но **не исправляются автоматически**. Реальные документы и точность распознавания не проверены.
- C6: ключевые серьёзные лекарственные риски отображаются в краткой ленте с названием каждого альтернативного варианта (PR #29). Браузер Preview и врачебная приёмка ещё не выполнены.
- Протоколы, Consilium, ECG/Radiology, библиотека, локальный RAG, клинические рекомендации и источники — в объединённом состоянии после PR #28; до реального Preview не объявлять сквозную работоспособность конкретного пути.
