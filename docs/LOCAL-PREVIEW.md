# Doctor Opus / Consilium — независимая установка и обновление Preview (C10)

Дата обновления: 16 ноября 2026. **Цель: простой и безопасный запуск ядра на 3207 без переустановки чужих приложений.** Это не развёртывание сервера и не вмешательство в Codex на 3107.

## Первичная установка на Mac

Нужен Node.js **22.18+** (в CI используется Node 22), Git и доступ к npm для **однократной загрузки** зависимостей. Если `~/Documents/Consilium-Preview` уже существует, **не выполняйте clone поверх него** — см. обновление ниже.

```sh
git clone --branch chatgpt-dev --single-branch https://github.com/vasiliys961/consilium.git ~/Documents/Consilium-Preview
cd ~/Documents/Consilium-Preview
npm ci --ignore-scripts
npm run check:preview
npm run dev:preview
```

Открыть **http://127.0.0.1:3207**. Не использовать `npm run dev` в Preview: обычный сценарий проекта занимает **3107** и принадлежит линии Codex.

`check:preview` читает состояние Node, ветки Git, каталога зависимостей и наличие необязательных модулей **без установки, без сетевого доступа и без чтения секретов**. Ветка `main` не допускается к запуску в роли Preview; внешний симлинк `node_modules` также блокируется. Если обнаружена ссылка, **не удаляйте её целевой каталог**; убедитесь, что вы работаете именно в независимой папке. Для чистой копии `npm ci --ignore-scripts` устанавливает зависимости в локальный `node_modules`.

**Важно:** отсутствие `OPENROUTER_API_KEY` не должно мешать открыть интерфейс, библиотеку и синтетические случаи, но платный клинический анализ будет недоступен. Не копируйте `.env.local` из основной копии, не публикуйте ключи и не запускайте реальные медицинские запросы для установки.

## Обновление существующего Preview

**Сначала сохраните изменения в браузере и остановите только процесс Preview** клавишами Control+C в терминале, где запущен порт 3207. Оставьте `3107` работающим. Затем в отдельном терминале именно папки Preview:

```sh
cd ~/Documents/Consilium-Preview
npm run update:preview
npm run dev:preview
```

`update:preview` самостоятельно выполняет безопасный порядок:

1. Проверяет, что это **отдельная копия**, текущая ветка точно `chatgpt-dev`, а `origin` соответствует `vasiliys961/consilium`.
2. Отклоняет запуск, если есть **незакоммиченные или новые файлы** в Git, симлинк на чужой `node_modules` либо занят порт 3207. Ничего автоматически не удаляется.
3. После разрешения запуска выполняет `git fetch --no-tags origin chatgpt-dev`, затем **только** `git merge --ff-only FETCH_HEAD`. Ни `reset --hard`, ни `git clean`, ни переключения на `main` нет.
4. Применяет `npm ci --ignore-scripts --no-audit --no-fund` **только в этой копии** и сообщает о результате. Дополнительные тяжёлые модели и дочерние службы не устанавливаются.

Если перед первым обновлением команда `update:preview` ещё не существует в старой версии, один раз вручную (при чистой ветке `chatgpt-dev`, с остановленным Preview) выполните `git fetch origin chatgpt-dev` → `git merge --ff-only FETCH_HEAD` → `npm ci --ignore-scripts`. После этого пользуйтесь одной командой.

**Обновление Git и npm не очищает IndexedDB браузера** и не меняет `.env.local`. История случаев остаётся в том же браузере и origin `http://127.0.0.1:3207`, если браузер не очистил данные. Safari и Chrome, а также `localhost:3207` и `127.0.0.1:3207` хранят разные данные — используйте прежний адрес. Сохраните резервную копию клинических случаев и оригиналов книг **до** важных обновлений. Переносить случаи между браузерами нужно отдельным защищённым архивом C9; перенос книги — C8.

## Опциональные модули, без автозагрузки

`npm run dev:preview` больше **не** запускает `scripts/ensure-native-protocols.mjs` и не устанавливает RU/Global протоколы при старте. Ядро, карточки, архивы и часть лёгких функций работают отдельно.

Для использования **двух оригинальных редакторов протоколов** после установки ядра врач **явно** выполняет в Preview:

```sh
npm run setup:protocols
```

Эта команда использует lock-файлы внутри `integrations/protocol/ru` и `integrations/protocol/en`, может скачивать существенный объём npm-пакетов и не должна запускаться для простой проверки ядра. Протоколы автоматически запускаются только при соответствующем действии врача и установленном исполнителе. Другие интеграции (Radiology, ECGFounder, Translator, тяжелые детекторы) **не** устанавливаются C10 автоматически и могут оставаться недоступными. Текстовые/визуальные веса библиотеки также отдельно устанавливаются командой `npm run setup:library-models`, только при необходимости и при наличии свободного места.

Режим Preview связывает браузерный адрес и серверные маршруты только с собственными портами. Не запускайте вторую Preview-копию параллельно на 3207. Если он занят, **не убивайте неизвестный процесс автоматически**: проверьте `lsof -nP -iTCP:3207 -sTCP:LISTEN`.

## Проверено и не проверено

GitHub CI устанавливает корневые зависимости через `npm ci --ignore-scripts` в чистом runner, выполняет `npm test`, TypeScript и Next.js build. Синтетические тесты C10 создают отдельный временный Git checkout и проверяют запуск без дочерних установок, отказ на `main`, опасном симлинке, локальных правках и чужом origin. Они не редактируют рабочие папки врача.

**Открыто:** реальный старт после чистого clone на macOS M1 с Safari, обновление работающего локального экземпляра после его остановки, перенос больших книг, установка дочерних программ и работоспособность внешних медицинских моделей. Не утверждать, что это проверено одним лишь зелёным CI.
