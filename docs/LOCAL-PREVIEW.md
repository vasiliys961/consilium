# Consilium Preview — независимый запуск на Mac

Этот режим предназначен для проверки изменений ChatGPT рядом с существующей установкой Codex. **Не** меняйте текущую папку Codex, не заменяйте её `.env.local` и не запускайте `npm run dev` из этой Preview-копии.

## Первая установка (Mac)

```bash
cd ~/Documents/Consilium-Preview
git fetch origin
git switch --track origin/chatgpt/preview-isolation
npm ci
npm run dev:preview
```

Если локальная ветка уже существует, используйте `git switch chatgpt/preview-isolation`, затем `git pull --ff-only`. Node.js 22.18 или новее. Режим проверяется в CI на Node 22; при проблемах на более новой Node версии пришлите точный вывод терминала.

Открыть в браузере: http://127.0.0.1:3207

## Разделение экземпляров

| Сервис | Исходная установка Codex | Preview ChatGPT |
| --- | ---: | ---: |
| Основное приложение | 3107 | 3207 |
| Ограниченный вход со смартфона | 3108 | 3208 |
| Radiology | 3110 | 3210 |
| Протокол RU | 3111 | 3211 |
| Протокол EN | 3112 | 3212 |
| Переводчик | 3113 | 3213 |

`npm run dev` по-прежнему запускает основной профиль на 3107. **Для нашей папки используйте только `npm run dev:preview`.** Preview-профиль выставляет `NEXT_PUBLIC_CONCILIUM_PREVIEW=1` и изменяет одновременно браузерные iframe-адреса, серверные интеграции, origin-проверки и порт телефонной передачи.

Каждая папка имеет собственные зависимости `node_modules`, .next и журналы. Случаи в IndexedDB отделены разными origin/портами. Однако Safari и Chrome и разные профили браузера имеют разные хранилища: создавайте только синтетические тестовые случаи.

## Отдельные ключи и интеграции

Preview не читает `.env.local` из исходных приложений Radiology, Protocol и Translator на рабочем столе. Он использует только окружение запуска и собственную локальную конфигурацию Preview, если она создана вручную. **Не копируйте ключи в чат, коммиты или GitHub Actions.**

Функции, требующие внешнего OpenRouter, могут быть недоступны без самостоятельно настроенного ключа. Нажатие «Анализировать» при настроенном ключе может привести к платному API-запросу. Специализированные модули также требуют собственных зависимостей и весов; `npm ci` в корне проекта не устанавливает все дочерние приложения. Наличие кнопки на странице не доказывает, что соответствующий модуль готов.

## Проверка

В терминале Preview должна появиться строка с `http://127.0.0.1:3207`. В другой вкладке терминала можно проверить:

```bash
curl -I http://127.0.0.1:3207
lsof -nP -iTCP:3107 -sTCP:LISTEN
lsof -nP -iTCP:3207 -sTCP:LISTEN
```

`lsof` на 3107 нужен только для наблюдения, ничего останавливать там не надо. При неизвестном конфликте порта Preview должен завершиться с ошибкой, а не переключаться на 3107. Неподключённые модули показывают состояние «не установлено»/«не запущено» и не должны обращаться к основным портам 3110–3113.

Остановить только Preview: `Control+C` в **его** терминале. Для сравнения открыть старый `http://127.0.0.1:3107` в другой вкладке.

## Ограничения проверки

CI покрывает типизацию, сборку и независимость таблицы портов, но не заменяет реальную проверку двух запущенных экземпляров на Mac. Интеграция со смартфоном, DICOM, клинические ответы и защиту медицинской информации необходимо проверять отдельно. Публичный Preview на Vercel **не** создаётся этим PR.
