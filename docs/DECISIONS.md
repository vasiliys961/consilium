# Consilium — журнал решений

## 2026-11-15. Ветвление и роли
- Один общий репозиторий `vasiliys961/consilium`; нового репозитория не создаём.
- `main` временно остаётся линией Codex, без вмешательства со стороны ChatGPT.
- `chatgpt-dev` — отдельная линия разработки ChatGPT; PR из `chatgpt/*` направляются сюда.
- Объединение проверенных изменений обратно в `main` — только после явного согласования владельцем. При переносе учитывать свежие коммиты Codex и конфликты.
- Отдельный локальный клон на Mac: `~/Documents/Consilium-Preview`, целевой порт 3207; исходная локальная установка с портом 3107 не затрагивается.
- Только смена порта недостаточна: адреса дочерних станций, передача со смартфона, проверки origin и независимость процессов требуют явной настройки и тестов.

## 2026-11-15. Архитектура медицинской системы
- Новая структура Consilium — основа развития. Из старого Doctor Opus Global выборочно заимствовать наиболее полезные элементы: адаптивный выбор специалистов, оценку разногласий, условную эскалацию и многораундовые обсуждения.
- Перенос не означает доказанной клинической пользы. Старый и новый алгоритмы нужно сравнивать на одинаковых наборах кейсов, сохраняя возможность отката.
- Сохранять local-first модель, покрытие анализа каждого материала, независимые первичные прочтения и возможность врачу пересмотреть каждый вывод.
- Нельзя считать отсутствие срабатывания ограниченных локальных правил лекарственных взаимодействий доказательством безопасности комбинации.

## 2026-11-15. Публикация
- Основной кандидат будущего веб-интерфейса — отдельный сайт на Vercel с локальным компонентом для тяжёлых исследований. На текущем этапе `git.deploymentEnabled=false` остаётся.
- Публичная облачная демонстрация разрешена только с синтетическими данными и адаптированными для облака функциями; публикация клинической системы и коммерческий доступ требуют отдельной проверки безопасности, клинических характеристик и применимых требований.
- GitHub Actions: инженерные проверки на стандартном runner без реальных данных пациентов и платных API.
