# Consilium — журнал принятых решений

## 2026-11-16 — будущее единое окно Doctor Opus и ambient-протокол

- Владелец подтвердил концепцию **врач объясняет задачу голосом или текстом → лёгкий помощник показывает реальные возможности и предлагает маршрут → врач подтверждает → открывается подходящий уже работающий модуль с контекстом случая → результат сохраняется после проверки**. Первый экран должен отвечать на вопрос «Чем Doctor Opus может помочь?». Никаких ручных технических настроек для врача.
- Medical Translator остаётся **дополнительным аксессуаром**, без обязательной глубокой интеграции в ядро. Начатую работу в `chatgpt/c11-translator-case-return-20261116` **не объединять** в `chatgpt-dev` сейчас. Принято только направление возможного повторного использования UI/аудио/транскрипции для отдельной функции ambient-протокола приёма.
- Для ambient: явное включение записи и согласие, локальное хранение по умолчанию, разделение исходной речи, перевода и медицинских фактов, контроль доз/чисел/отрицаний, запрет выдуманных объективных данных, редактируемый RU/Global черновик, сохранение только после проверки врача. Не включать микрофон или платный голос автоматически. Подробности: [PHYSICIAN-AGENT-AMBIENT-VISION-2026-11-16.md](PHYSICIAN-AGENT-AMBIENT-VISION-2026-11-16.md).
- Это **будущие P2 этапы**, а не готовая реализация; сначала оставшиеся клинически значимые C11 и браузерная приёмка. Ветки `main`/3107 не изменяются.

## 2026-11-16 — C11: модуль — одна кнопка врача, безопасный возврат протокола

- Требование владельца продукта зафиксировано в `AGENTS.md`: **нажал модуль → он открылся, получил случай, работает, сохранил подтверждённый результат в той же карточке**. Врач не устанавливает пакеты, не вводит команды, не выбирает порты или технические модели. Первоначальная поставка модулей — ответственность установки/администрирования; полная автоматизация чистой установки и сквозная проверка в браузере ещё открыты.
- [PR #44](https://github.com/vasiliys961/consilium/pull/44): возврат RU/Global-протокола переводится в атомарную очередь записи, защищён от устаревшего снимка карточки, повторов и несовпадения языка. Сохранены редакции прежнего документа с тем же ID, решения врача и материалы не заменяются. Реальное открытие двух протоколов на 3207 пользователь подтвердил; сохранение после нового кода требует проверки. См. [C11 контракт модулей](C11-CLINICIAN-MODULE-CONTRACT-2026-11-16.md).

## 2026-11-16 — C11: безопасный возврат генетического заключения в случай

- [PR #42](https://github.com/vasiliys961/consilium/pull/42) объединён в `chatgpt-dev`. Возможность сохранения успешной консультации генетика без нового файла принципиальна: ранее кнопка была заблокирована из-за `!files.length`, несмотря на завершённое заключение.
- Врач явно выбирает повторное использование уже загруженного в случай VCF с валидным SHA-256. Заключение привязывается к тем же хешам, ID случая и вопросу на момент анализа. Если VCF сменился, старое заключение не выдаётся за чтение новой версии. Повторное сохранение того же анализа не дублирует историю.
- Исходные решения врача, предыдущие источники, анализы и вложения не перезаписываются; закрытый случай и неправильный case ID отвергаются. Это проверка технической целостности, не достоверности генетического диагноза. Реальная браузерная приёмка C11 и другие модули ещё открыты.

## 2026-11-16 — C10: ядро Preview устанавливается без дочерних модулей

- [PR #40](https://github.com/vasiliys961/consilium/pull/40) объединён только в `chatgpt-dev`. Для основной ChatGPT-копии отказались от скрытой автоматической установки протоколов при каждом `npm run dev:preview`. Врач может запустить лёгкое ядро и карточки без оплачиваемого анализа и дополнительных больших зависимостей; при необходимости `npm run setup:protocols` вызывается отдельно.
- Для независимой копии 3207 добавлен локальный read-only `check:preview` и явный `update:preview`: только чистая ветка `chatgpt-dev` с подтверждённым Git origin, остановленным портом 3207, локальными `node_modules` без ссылок на чужие папки; обновление только fast-forward и локальный `npm ci --ignore-scripts`.
- Никогда автоматически не останавливать 3107, не редактировать `main`, .env.local, исходные Desktop-проекты и их веса, не удалять браузерные случаи. CI и тесты с синтетическими временными Git-папками не заменяют проверку на реальном Mac; перед обновлением врач сохраняет резервные копии по прежнему origin 3207.

## 2026-11-16 — C9: отдельный переносимый клинический случай

- [PR #38](https://github.com/vasiliys961/consilium/pull/38) объединён **только в `chatgpt-dev`**. Дополнен экспорт одного случая в отдельный файл `.doctor-opus-case`, без серверной отправки, с паролем, PBKDF2/SHA-256 (600 000 итераций), AES-256-GCM и аутентификацией содержимого.
- Импорт не подменяет запись с совпадающим ID: применяется атомарный `IndexedDB.add()`, а создание отдельной копии требует явного выбора врача. Внешние книги не переносятся автоматически; история источников и выбранных фрагментов остаётся частью записи случая.
- Отдельный архив содержит в зашифрованном виде **и локальные персональные поля**, если они присутствуют в случае. Пароль от файла не является паролем локального хранилища; он не сохраняется и не может быть восстановлен. Выводы из перенесённого случая остаются историческими, не вновь подтверждёнными моделью или врачом.
- [Тест C8 PR #37](https://github.com/vasiliys961/consilium/pull/37) доказал на синтетической книге, что после восстановления реально находится исходная страница с релевантным текстом и OCR. Реальная браузерная приёмка C8 и C9 остаётся открытой.

## 2026-11-16 — C8: переносимый архив одной книги

- [PR #35](https://github.com/vasiliys961/consilium/pull/35) объединён в `chatgpt-dev`. Один локальный архив `.doctor-opus-book` хранит **оригинальный PDF/TXT/MD, страницы, OCR и текстовые векторы** до 64 МБ исходника. Экспорт/импорт и SHA-256 выполняются в браузере. Не переносить файлы автоматически на сервер.
- Не импортировать повреждённые архивы и исполняемые HTML-оригиналы. При восстановлении книга, текст и векторы сохраняются атомарно в IndexedDB; прав на исходную папку и старого абсолютного пути нет. Визуальный атлас **не перенесён** — помечать потребность перестроить, не показывать его как готовый.
- Больше 64 МБ, многокнижный потоковый экспорт, перенос визуальных векторов и реальная Safari/Chrome проверка остаются будущими действиями. Архив книги и резервная копия клинического случая — **разные файлы**.

## 2026-11-16 — C7 и C8: источник и личная библиотека

- C7 [PR #31](https://github.com/vasiliys961/consilium/pull/31) и [#32](https://github.com/vasiliys961/consilium/pull/32) объединены только в `chatgpt-dev`. Доступный абзац и связанный тезис являются материалом для оценки врачом, но не доказывают применимость рекомендации. Пользователь проверил, что новые источники находятся на Preview 3207 после повторного анализа.
- C8 [PR #33](https://github.com/vasiliys961/consilium/pull/33) объединён только в `chatgpt-dev`: предотвращать **точные бинарные дубли** книг до 64 МБ, не смешивать редакции, а при изменённом/недоступном подключённом оригинале не выдавать прежние выдержки за актуальные. Старые индексы не удалять самовольно; изменения оригинала проверять по размеру/mtime и ясно обозначать ограничения этой проверки.
- Файлы библиотеки и эмбеддинги остаются локальными в рамках текущей архитектуры; `navigator.storage.estimate()` — оценка всех данных данного origin, не гарантия доступного места именно под книги. Реальная приёмка C8 в браузере остаётся открытой.

## 2026-11-16 — интеграция и клиническая граница

- Разрешено объединять **проверенные изменения в `chatgpt-dev`**, не в `main`. 16 ноября PR #28 squash-merged (commit `b3e9577`), затем PR #29 с C6 и документацией squash-merged (commit `5e8c584`), без деплоя и без обновления работающего Preview.
- Разработка приоритетно обеспечивает врачебную ценность: ответы, безопасность назначений, понятный разбор и источники. Технические улучшения — лишь при подтверждаемом эффекте.
- Пользователь выбрал ограничиться **синтетическими тестами**. Прогон 500 вариантов C3 не называется клинической валидацией. Реальные пациентские данные и платные медицинские вызовы для этих тестов не используются.
- Значимые лекарственные риски показывать рядом с клинической тактикой; *альтернативные планы не являются совместными назначениями*, а отсутствие правила взаимодействия не подтверждает совместимость.
- OCR: недостающие страницы, числа, знаки, отрицания не исправлять догадкой. Оригинальная копия локальна, врачу указать, что требуется сверить.

## 2026-11-15 — разграничение окружений

- Один репозиторий `vasiliys961/consilium`. Codex использует `main` и локальный порт 3107. ChatGPT работает в `chatgpt-dev` через feature-ветки, независимый Preview — 3207.
- Вторая локальная копия, интеграции и ретранслятор телефона должны быть изолированы от Codex; простая смена порта не гарантирует изоляцию.
- Не передавать идентифицирующие данные пациентов в публичный GitHub, CI, тестовые PDF и документы.
- Все LLM-вызовы текущего приложения — только через OpenRouter; без резервного Polza. Публичный продакшен-деплой без явного согласия запрещён.
