# C11 — повторное открытие сохранённых результатов

16 ноября 2026. Изменения только в ChatGPT Preview-ветке; `main` и окружение Codex не затрагиваются.

## Реализовано

- В карточке случая отображаются сохранённые документы самостоятельных протоколов RU/Global; врач может снова открыть редактор в правильной языковой версии и просмотреть прежние редакции.
- Сохранённые описания Radiology повторно открываются из карточки и сопровождаются оценкой привязки оригинальных файлов: `linked` только при точном SHA-256 для **каждого** исходного ключа; `stale` если оригинал отсутствует; `unverified` без надёжных ключей.
- Для случая с VCF доступен возврат в генетический модуль. Результаты генетического разбора остаются в ленте анализов; наличие VCF не выдаётся за завершённое заключение.
- Обзор ничего не отправляет на сервер и не запускает модели. Использует существующие `persistNativeProtocol`, `persistRadiologyReport`, `mergeGeneticsIntoCase`, не меняя сохранённые клинические данные и не переписывая дочерние модули.

## Синтетические проверки

`lib/c11-module-overview.test.ts`: строгое сопоставление SHA-256, различение потерянного оригинала и неподтверждённой связи, правильные язык/версия редактора, разделение прежних редакций RU и Global.

## Границы готовности

Сквозная браузерная приёмка на Mac `127.0.0.1:3207` остаётся обязательной: из карточки открыть RU и Global, изменить и сохранить, проверить прежние редакции и возврат после перезапуска Preview; аналогично Radiology, VCF и анализы. GitHub CI **не** доказывает работу локальных служб, микрофона и DICOM на Mac. Реальные данные пациентов не использовать. Медицинский переводчик остаётся дополнительным аксессуаром; экспериментальная ветка не объединена.
