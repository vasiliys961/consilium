# Проверка переработанного механизма — 7 ноября 2026

## Подтверждено

- Автотесты модульных контрактов и логических цепочек: 151 тест без ошибок (включая новые тесты, перечисленные ниже).
- TypeScript проверяется без отключения ошибок типов.
- Итоговая production-сборка после завершающих правок выполнена успешно.
- В браузере загружен **синтетический**, а не пользовательский `ecg2.png`; вопрос — «что здесь». Первая проверка обнаружила реальный тайм-аут визуальной модели. После изменения срока ожидания повторный запрос дал завершённый профильный разбор, статус файла стал «прочитано», посторонние статьи отсутствовали, результат сохранён в локальной карточке.
- Переключение русского/английского интерфейса проверено в браузере. Сохранённый клинический текст не переводится незаметно при смене интерфейса.
- Живой HTTP-запрос с отдельной тестовой библиотекой вернул ответ на испанском, один найденный фрагмент и стабильную ссылку `rag:...`; внешняя поисковая выдача не использовалась.
- Ограниченный телефонный LAN-вход: загрузка синтетического TXT вернула HTTP 200; рабочее место получило файл; страница телефона вернула HTTP 200; врачебный `/api/v1/cases` через LAN-вход вернул 404.
- Локальные PDF-инструменты на этом Mac действительно извлекли текст и отрисовали страницу синтетического PDF без внешнего API. Этот тест не был пропущен.

## Новые регрессионные сценарии

1. `ecg2.png` → чтение пикселей ЭКГ → ответ с находками, без литературного поиска или лишнего общего пересказа.
2. Обрезанный ответ → ограниченный повтор → явная ошибка, без передачи сырого JSON в клинический текст.
3. Сбой локальной проверки приватности → изображение не передаётся, причина показывается.
4. Успешное чтение обычного снимка обновляет журнал; имя файла не подменяет фактическую модальность.
5. Документ и изображение вместе попадают в общий разбор, ни один поток не теряется.
6. Если финальный синтез не удался, завершённый профильный разбор сохраняется и ошибка последнего этапа называется явно.
7. Дубликаты имён не объединяются в один источник.
8. Библиотека врача не становится «данными пациента», несуществующие фрагменты не фабрикуются.
9. Посторонние статьи о растениях/лимфомах/эндокардите отбрасываются в поиске по другой теме.
10. Помощник различает отсутствие данных, готовность, обработку, отказ, проверку врачом и наблюдение.
11. Временные точки выборки видео и граница охвата сохраняются; неподдерживаемый TIFF даёт явную причину отказа.
12. Ошибочные типы JSON, библиотек, медиа, масок и задач отклоняются до вызовов моделей.
13. Неподтверждённые числовые оценки ЧСС/интервалов не выдаются за измерения.

## Что этой проверкой не подтверждено

- Медицинская точность разборов на реальных клинических случаях и превосходство над мировыми аналогами.
- Все форматы и все варианты кодеков; закрытые DICOM, старые DOC/XLS и отдельные проприетарные ЭКГ остаются ограниченными.
- Работа физической камеры/микрофона реального смартфона: проверены транспорт и ограничения доступа, а не устройство.
- Полный анализ движения/функции по видео, полные объёмы КТ/МРТ и доступность всех внешних весов.
- Серверное шифрованное хранилище, многопользовательский режим и полноценная резервная копия.
- Свободное чтение любых сайтов и платных статей. Доступны публичный поиск с метаданными/абстрактами и предоставленные врачом текстовые документы; обхода закрытого доступа нет.
