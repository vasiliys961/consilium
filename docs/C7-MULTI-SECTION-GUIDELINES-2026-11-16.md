# C7 — несколько цитируемых абзацев одного руководства

Дата: 16 ноября 2026. Функциональный пакет после PR #31.

## Для врача

Если Европа PMC возвращает разрешённый к чтению и воспроизведению XML статьи, поиск сохраняет **до трёх релевантных абзацев**, по возможности из разных разделов. Их происхождение не смешивается: `pmc:PMC...:<номер абзаца>`, глава/раздел и конкретный текст передаются клиническому синтезу. Если ИИ ссылается на дополнительный абзац, панель источников сохраняет эту привязку и показывает соответствующий текст.

Библиографическая запись и аннотация остаются в списке, даже если извлечь полный текст не удалось. Один абзац не выдаётся за весь документ; три — также не доказывают полноту руководства.

## Технические границы

- Использован уже существующий запрос XML Europe PMC, без новых платных API-вызовов, фоновых сервисов или повышенной кратности сетевых обращений.
- Действующие ограничения чтения XML (2 МБ, 4 с, проверка идентификатора PMID и допустимой лицензии) остаются; обход платного доступа не добавлен.
- Одна запись публикации раскрывается в до трёх отдельных записей **только при формировании допустимых evidence-ключей и врачебного представления**. Сам список публикаций в поиске не дублируется.
- Дополнительный текст может увеличить контекст модели. Ограничено тремя фрагментами на статью и прежними лимитами числа результатов.
- При отсутствии нужного абзаца, неполном тексте, иной лицензии или неработающем API продолжается прежний путь аннотации/библиографии; отсутствие извлечённого фрагмента не означает отсутствия доказательств.
- Оценка соответствия тезиса данным остаётся *консервативной эвристикой*, не экспертной медицинской валидацией. Проверка GRADE, популяции и строгого сопоставления PICO остаётся будущей работой.

## Приёмка

Синтетические XML со множеством секций и единым PMID; проверка трёх различных ключей, соответствующих абзацев и ограничения до трёх; отсутствие выдуманных ссылок для аннотации. Дополнительная регрессия: утверждение, привязанное ко второму абзацу, не связывается с первым. Глобальные npm test/typecheck/build подтверждаются CI PR и затем post-merge CI.

## Что ещё не закрыто

Полнота извлечения всех клинически важных разделов, действительные версии крупных руководств, PICO/включающие и исключающие критерии, реклассификация уровня рекомендаций и независимая проверка клинической правильности на реальных документах. Браузерная приёмка Preview остаётся отдельной.
