## Обновление после врачебной обратной связи — свободный список, один недорогой вызов

**Клинический недостаток первоначальной C3:** отсутствие локального правила для произвольного препарата не равно отсутствию взаимодействия; перечисление 13 правил или добавление бисопролола не решает задачу охвата. Выделен основной путь **одного предварительного LLM-разбора без словаря и лимита 4 инструкций**, по явному нажатию врача. По умолчанию `Gemini Flash`, серверный параметр `MEDICATION_CHECK_MODEL` может выбрать другую доступную через OpenRouter модель. Ввод можно давать на любом языке; локальные правила остаются лишь бесплатными подсказками.

Это **не** доказанная проверка по действующим инструкциям или DDI-базе: в UI всегда отображается отсутствие независимой проверки источников. Нельзя выдавать отсутствие находок модели за совместимость. Старый режим с выбранными инструкциями остаётся в коде отдельно, но **не требуется** для простого лекарственного разбора. Сценарий запуска в кейсе через полный консилиум остаётся отдельным, более затратным путём.

Оплата: одна модельная попытка по запросу врача, `retryInvalidResponse:false`; цена в UI — **расчётная по токенам**, не квитанция OpenRouter. При отсутствии API-ключа/ошибке — явный отказ, а не безопасное заключение. Синтетический тест использует 8 препаратов с разными языками, не реальные данные пациентов.

# C3 — клиническая проверка лекарств: первая предметная итерация

Дата проверки источников: **2026-11-15**. Статус: **синтетические регрессии и код**, не клиническая валидация и не полный справочник взаимодействий.

## Что реально добавлено

Существующий `lib/drug-interaction-rules.ts` расширен с 4 до **13 локальных проверок** (без новой службы, модели или платного API). Интерфейс различает **текущий приём**, **планируемое назначение**, **отмену** и **взаимоисключающие альтернативы**. Отменяемые препараты не считаются продолжающимся приёмом; каждая альтернатива проверяется как отдельный сценарий относительно базового списка. Положительная находка содержит риск, клиническое действие, мониторинг, степень риска, источник и раздел инструкции. Незнакомые и местные/глазные препараты не получают ложного заключения «безопасно».

С учётом введённой врачом **СКФ** применяется конкретное правило инструкции метформина: ниже 30 — противопоказание, 30–44 — не начинать новый курс, а при уже проводимой терапии — отдельно оценить пользу и риск продолжения. Указанный врачом декомпенсированный цирроз вызывает предупреждение для симвастатина; явно подтверждённая тяжёлая печёночная недостаточность — предупреждение для апиксабана. Неуказанные функции органов не подменяются нормальными значениями.

## Проверяемая матрица (20 синтетических сочетаний)

| Пары с ожидаемой находкой | Риск |
|---|---|
| Силденафил + нитраты / риоцигуат | Противопоказано |
| Симвастатин + кларитромицин / эритромицин | Противопоказано |
| Спиронолактон + лозартан / триметоприм | Контроль / значимый риск |
| Варфарин + ибупрофен / кларитромицин | Кровотечение / МНО |
| Апиксабан + ибупрофен / клопидогрел / рифампицин | Кровотечение / снижение экспозиции |
| Литий + напроксен / эналаприл | Токсичность |
| Дигоксин + амиодарон | Повышение концентрации |

Отрицательные контрольные примеры: варфарин + метформин; варфарин + глазной ибупрофен; варфарин + ибупрофен-гель; «наблюдение за лозартаном» вместо назначения; симвастатин + азитромицин; апиксабан + парацетамол. Отрицательный тест означает **нет правила в данном ограниченном наборе**, не отсутствие взаимодействий в полной базе.

Отдельные регрессии: статусы current/current, current/proposed, proposed/proposed; отмена варфарина до назначения; две альтернативы варфарин/апиксабан без объединения; метформин при СКФ 26, 38 и 65, в том числе «начало» против «продолжения»; подтверждённая тяжёлая печёночная патология и неизвестная функция почек.

## Что остаётся до клинической приёмки C3

1. Провести независимую врачебную оценку на разрешённых синтетических случаях без подсказки ожидаемого ответа; посчитать чувствительность к опасным пропускам, ложные тревоги и полезность предложенного действия.
2. Проверить комбинированные препараты, формы и сложные схемы из 5+ лекарств. `MAX_DRUG_LABELS=4` остаётся **ограничением отдельной модельной проверки инструкций**, а не числом локальных правил.
3. Проверить на Preview 3207 отображение источников, сохранение контекста, вариант с отменой и самостоятельную оценку альтернатив; только после обновления владельцем и без платных вызовов.
4. Не объединять клиническую уверенность и инженерный статус: успешный CI не означает, что C3 клинически проверен.
