## Долг по приёмке W1/W2 (не делать автоматически)

1. Только с синтетическим случаем в **том же** браузере и origin `127.0.0.1:3207`: «Что умеет Doctor Opus?» → бесплатная справка; «Найди инструмент для анализа ЭКГ» → корректная существующая страница, без ложного утверждения о выполненном анализе.
2. Клиническая реплика → профильный/универсальный специалист → ручная смена профиля → уточнение → исходный вопрос сохранён. Проверить голосовой ввод и добавление документа с ручным просмотром извлечённого текста.
3. Для W2: исходный случай → существующий модуль «Спросить специалиста» → **только после отдельного согласия на стоимость/данные** один реальный модельный вызов → дождаться завершённого ответа → нажать «Сохранить этот ответ в клинический случай» → вернуться в карточку → обновить страницу → открыть сохранённый ответ и экспорт. Не принимать открытие модуля за выполненный анализ.
4. Проверить неуспешную запись, закрытый/удалённый случай, повторное сохранение, устаревший autosave. Не запускать платные проверки автоматически.
5. До обновления Preview сохранить резервную копию синтетических случаев; обновление выполнять только для остановленного `3207` по [LOCAL-PREVIEW.md](LOCAL-PREVIEW.md). `main`/3107 не менять.

## При следующем разрешении начать W3 (пока НЕ выполнять)

Опираться на **существующие**:
- [C14 — оригинальные RU/Global Ambient](C14-NATIVE-AMBIENT-FIRST-INTEGRATION-2026-11-16.md)
- [C14 — OpenRouter STT и 11 языков](C14-MULTILINGUAL-AMBIENT-OPENROUTER-2026-11-16.md)
- [C12 — локальный аудит фактов Ambient](C12-AMBIENT-DRAFT-FACTUALITY-2026-11-17.md)
- [Концепция врачебного агента и Ambient](PHYSICIAN-AGENT-AMBIENT-VISION-2026-11-16.md)

**Первый целевой поток W3:** открыть существующий RU протокол из синтетического случая → отдельное согласие и ручное начало записи → стоп/отмена → проверка транскрипта → проверка критических фактов (лекарство, мг/мкг, кратность, «нет»/«есть», неопределённая роль) с привязкой к исходным репликам [Tn] и честными временными метками → врач редактирует → явно создаёт черновик → сохраняет в **тот же случай** → повторно открывает; затем тот же путь для одного языка Global.

Контрольные искусственные ошибки: «5 мг» в исходной реплике vs «10 мг» в черновике, несуществующий `[T99]`, «не принимает» vs «принимает», речь врача не становится жалобой пациента, неизвестные SpO₂/АД не выдумываются. Изменённая расшифровка сбрасывает старые подтверждения. Нельзя заявлять, что атрибуция врача/пациента подтверждена лишь по метке Speaker 0/1. Отдельно проверить корректное завершение длинной записи и частичные/ошибочные STT.

**Границы:** никакого автозапуска микрофона, фонового платного распознавания или генерации после завершения записи; Medical Translator — необязательный аксессуар. Использовать OpenRouter по правилам `AGENTS.md`. Аудио потенциально содержит личные данные; нужна отдельная проверка согласия и хранения. Синтетика/CI не заменяют врачебную оценку.
