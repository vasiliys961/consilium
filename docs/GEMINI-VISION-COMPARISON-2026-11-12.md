# Проверка Gemini на 20 открытых снимках · 12.11.2026

Выполнены 60 реальных запросов через OpenRouter: Gemini 3.8 Flash, Gemini 3.1 Pro Preview, Gemini 4 Argon. Выборка VQA-RAD test: 20 разных изображений (9 рентгенограмм, 6 КТ, 5 МРТ), по одному изображению и контрольному вопросу на запрос. Приложение и модели по умолчанию не менялись.

Совпадения с контрольными ответами с учётом явного эквивалента «head of pancreas»: Flash 12/20, Pro 12/20, Argon 15/20. Строгое строковое сравнение: 12/20, 11/20, 15/20. Частичные ответы не засчитывались как полные совпадения.

По API usage.cost: Flash $0.04004175; Pro $0.10129; Argon $0.112792; суммарно $0.25412375, без комиссии пополнения и конвертации. Среднее время: 5.9 / 5.5 / 11.6 с соответственно. Все 60 квитанций сохранены с ID ответа, возвращённой моделью, usage и текстом. Отказов, автоматических повторов и замены модели не было.

Вывод: на этой выборке у Flash нет преимущества над Pro по контрольным вопросам, Argon выглядит перспективнее. Выборка мала и целевая; единичные изображения не заменяют полные серии, а свободные описания не оценивались радиологом против полных эталонных заключений. Нельзя трактовать 15/20 как клиническую точность модели или достаточное основание для автоматической замены. Открытый набор может быть известен моделям.
