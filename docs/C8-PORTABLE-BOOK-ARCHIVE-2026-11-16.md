# C8 — переносимый архив одной книги

Дата: 16 ноября 2026. Рабочая ветка `chatgpt/c8-portable-book-archive-20261116`. Разработка касается только `chatgpt-dev`.

## Врачебный сценарий

В разделе `/library` у книги есть действие **«Сохранить архив книги»**. В него входят **полный исходный файл**, извлечённые тексты страниц и OCR-фрагменты, сохранённые текстовые эмбеддинги (модель `Xenova/multilingual-e5-small`, размерность 384). Книга переносится на другой компьютер через файл `.doctor-opus-book`; действие **«Восстановить архив книги»** принимает его в браузере и создаёт отдельную запись библиотеки, если идентичной книги ещё нет. Источник из выбранной папки после восстановления становится **копией в браузере**; права на папку и локальные пути не передаются.

Архив не отправляет данные на сервер и не использует облачные модели. Создание/восстановление выполняется через локальный IndexedDB и браузерный WebCrypto.

## Целостность и границы

- Архив содержит сигнатуру/версию формата, размер метаданных, SHA-256 метаданных и SHA-256 полного исходного файла. Изменение, усечение, нарушение размера или неизвестная версия отвергаются **до записи**.
- Метаданные проходят ограничение размера и структурную проверку, включая типы страниц, OCR, модель и размерность векторов. При восстановлении формируется новый ID и новые ID фрагментов; старые пути/дескрипторы не используются. Источник, страницы, OCR и векторы сохраняются одной IndexedDB-транзакцией.
- Предотвращается случайный повторный импорт архива, если локально уже доступен оригинал с таким SHA-256.
- Если оригинал подключённой книги изменился или недоступен, архив не создаётся. Проверка быстрого изменения — размер и mtime, дополнительная проверка SHA, если исходно сохранённый отпечаток существует.
- Для контроля RAM размер исходного файла в первом варианте ограничен **64 МБ**, а сериализованные метаданные — **32 МБ**. Большие книги остаются в библиотеке и могут экспортироваться как обычный оригинал. Это **не полный архив всей библиотеки**.
- **Не переносится визуальный индекс**: CLIP-векторы изображений, регионов и миниатюры, поэтому `imagesIndexed=false` и пользователь должен запустить обычный «Полный индекс» для изображений. OCR-текст и текстовые эмбеддинги переносятся.
- Переносимые архивы не включают истории клинических случаев, ключи API, разрешения к папкам или пользовательские данные вне конкретной книги.
- Тождество по байтам не равнозначно совпадению издания или научной актуальности. При восстановлении не подтверждается клиническая применимость содержимого. Индекс модели из старого файла не валидирует медицинские тезисы.
- Реальные браузеры Safari/Chrome и большие PDF пока не проверены; синтетические тесты и сборка CI — отдельный уровень проверки.

## Проверка

Синтетическая книга из двух страниц: сохранить → архивировать → удалить локальный экземпляр → восстановить. Сверить исходный Blob, страницу, векторы 384, OCR, замену OCR после восстановления и отсутствие ложного флага визуального индекса. Отдельно проверять повреждение сигнатуры/заголовка, метаданных, исходного файла и усечённый архив без частичной записи; повторное восстановление не создаёт второй дубль.
