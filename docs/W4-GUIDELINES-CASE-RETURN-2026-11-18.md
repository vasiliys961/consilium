# W4 — клинические рекомендации возвращаются в случай

18.11.2026. Ветка `chatgpt/codex-w4-guidelines-case-return-20261118`, поверх опубликованного пакета #96. Сам поиск и его модели не переписаны. Новых платных вызовов нет.

## Исправленный разрыв маршрута

Раньше `/guidelines` позволял искать, редактировать и скачать рекомендации, но терял выбранный случай при возвращении, не сохранял ответ/правки и не возвращал подборку в карточку.

- Модуль принимает текущий случай из ссылки и позволяет выбрать его явно. Передача темы из прежнего разбора привязана к владельцу; тема и клинический текст не помещаются в URL.
- Запрос, ответ и текущие правки сохраняются в локальном черновике **только своего случая**. Неудачный новый поиск не очищает прежний ответ. Смена языка не переводит/перезапускает уже полученный ответ.
- Кнопка «Сохранить рекомендации в случай» добавляет подборку в сохранённые результаты и её точную копию в `library` — справочные материалы следующего разбора. Это не новая клиническая оценка, диагноз, решение врача или назначение.
- Сохраняются исходный ответ модели, текущий текст врача, тема, язык, режим, модель, токены и именно **расчётная** стоимость. Детали модели/расходов свёрнуты. Ссылки не объявляются проверенными первоисточниками.
- Повторное сохранение той же версии не создаёт дубль. Правки сохраняются отдельной версией; старые остаются в истории, но одновременно в следующий разбор передаётся **одна выбранная редакция того же ответа**.
- Из карточки открывается точная сохранённая подборка по ID без модельного запроса. Отсутствующий ID не подменяется другим ответом. Закрытый/удалённый/чужой случай не принимает новые записи.
- Самостоятельный результат может создать новый случай с подборкой без выдуманных данных пациента. При выходе с несохранённой самостоятельной работой есть одно предупреждение о потере данных; самостоятельный черновик пока хранится только в памяти страницы.
- Копирование зашифрованного случая переносит черновики, версии и справочные файлы, меняя только проверенного локального владельца.

## Проверки

- **1248 тестов**, TypeScript и production build проходят.
- Новые проверки: границы ответа API, привязка темы/языка/владельца, изоляция и восстановление черновиков A/B, атомарное добавление к последнему состоянию, неизменность фактов/решений/материалов пациента, SHA-256 справочного файла, повторное сохранение, редакции и единственная активная версия, закрытый/удалённый/чужой случай, зашифрованная копия, новый случай из самостоятельного ответа, десять языков интерфейса.
- Реальные режимы поиска по-прежнему обслуживает существующий `/api/protocols/search` и OpenRouter-only адаптер. Автоматических повторов/новых провайдеров/моделей нет. Проверка нового провайдерного ответа не выполнялась; локальные тесты используют явный синтетический ответ `synthetic-no-provider-call`.
- Приёмка в установленном интерфейсе и CI записываются ниже после выполнения. Тестовый зашифрованный случай содержит явный синтетический ответ, а не имитацию реальной медицинской консультации.

## Границы

Очередь записи остаётся общей для модулей внутри вкладки; межвкладочная блокировка ещё не принята. Случай хранит текущий незавершённый ответ и явно сохранённые версии; самостоятельную работу следует сохранить в новый случай или файл перед уходом. Платный поиск, клиническая достоверность и актуальность ссылок не подтверждаются проверкой локального возврата.
