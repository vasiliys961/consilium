# C13 — разговорный LLM-помощник врача, первый этап (17.11.2026)

**Цель.** Врач на первом экране Doctor Opus вводит вопрос в свободной форме, может уточнять задачу в последовательном диалоге и получает объяснение, какие из уже подключённых инструментов следует открыть. Это **навигация и организация врачебной работы**, не новый диагностический консилиум и не исполнитель автономных действий.

## Прямой врачебный сценарий

1. На `/` или в выбранном клиническом случае виден помощник (PR #54). Бесплатный маршрут по правилам C13 остаётся и не требует ключа/LLM.
2. Врач набирает задачу и выбирает отдельную кнопку **«Обсудить с ИИ · OpenRouter»**. Первый экран и обычная навигация никогда не вызывают модель автоматически.
3. Перед каждой отправкой появляется штатная проверка персональных данных `PrivacyReview` (исходники и само дело не загружаются), текст проверяется врачом и подписывается HMAC с сроком 15 минут. Отказ закрывает действие без запросов к модели. Передаются лишь последние реплики локального разговора и новое сообщение, без файлов пациента, аудио, ФИО и локального идентификатора случая.
4. Встроенный OpenRouter-шлюз вызывает **один** `google/gemini-3.8-flash` с лимитом вывода 450 токенов, таймаутом 18 с, без дорогих fallback-моделей и повторов при невалидном ответе. Базовый `OPENROUTER_API_KEY`, дополнительных ключей не требуется.
5. LLM возвращает JSON: короткое пояснение, не более одного уточняющего вопроса и до четырёх имён инструментов. Бэкенд принимает **только белый список C13**, формирует названия и причины шагов по локальному каталогу, и лишь показывает врачу ссылки. Ни одна функция не исполняется от имени модели.
6. Врач может ответить в том же текстовом поле; краткая история сохраняется только в React-состоянии вкладки. При смене случая или закрытии панели запрос прерывается, история не записывается на сервер и не уходит в архив случая без отдельного действия.
7. В карточке случая штатный переход в модуль сохраняет контекст/ID случая согласно контракту C11. Без выбранного случая предлагается создать его; автоматического создания, анализа или сохранения нет.
8. При ошибке/отсутствии ключа отображается локальная (бесплатная) маршрутизация, **без ложного утверждения, что LLM ответила**. Если API занят (1 активный запрос и не более 12 за минуту на локальный процесс), запрос не повторяется сам. Фактическая стоимость не выдаётся: при наличии счётчиков токенов показывается лишь приблизительная USD-оценка по тарифным константам. Участие провайдера и стоимость следует сверить по счёту OpenRouter.

## Безопасность

- Никаких прямых назначений, дозировок, диагнозов, чтения файлов, инструментальных API-вызовов или входа в другие сервисы от имени LLM.
- Персональная информация и беседа **не гарантированно полностью обезличиваются автоматически**. Врач проверяет редактор перед отправкой; не использовать реальные данные пациентов до отдельного разрешения и оценки условий облачного провайдера.
- Текст считается недоверенными данными, а команды модели валидируются против закрытого перечисления `PhysicianTool`. URL модуля формирует `physicianTaskHref`, а не модель.
- Ограничены размер JSON 16 КБ, длина подписанного текста 6500 символов, объём ответа LLM 1600 символов, количество предлагаемых модулей и конкурентность. Только loopback origin; публичный endpoint не предусмотрен.
- Базовые рекомендации в области медицины даёт отдельный клинический разбор/консилиум. Этот помощник только объясняет последовательность действий; результаты должны подтверждаться врачом.

## Отложено

- Самостоятельная работа агента с инструментами (tool calling, MCP, поиск в файлах пациента, сохранение результатов) — **не включать** до сквозной браузерной приёмки C11/C14 и отдельного проектирования разрешений/чекпойнтов.
- Голосовое управление через аксессуар-переводчик и ambient-режим — отдельные маршруты; никакого фонового микрофона.
- Долговременная память и многопользовательская идентификация — не создаются.
- Реальное качество диалога на 10+ языках, задержка и цена облачного вызова — не проверены синтетическими CI. Для браузерной приёмки использовать вымышленные задачи и существующий локальный ключ.

## Проверка на Mac Preview

В отдельной копии `~/Documents/Consilium-Preview` после merge PR и успешного CI: остановить **только** 3207, `npm run update:preview`, затем `npm run dev:preview`. Проверить: приветствие, бесплатный маршрут, подтверждение передачи для ИИ, ответы «есть КТ и ЭКГ» → уточнение «нужен протокол», объяснённые модули, переход к тому же случаю, отказ согласия без платного запроса, ключ отсутствует → локальная подсказка, отсутствие микрофона и автоматического запуска моделей.

**Не менять** `main`, порт 3107, локальные ключи, самостоятельные протоколы и Translator.
