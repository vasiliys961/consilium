# Интерфейс DOCX VCF и журнал терминала

Обновление от 7 ноября 2026.

## Десять языков интерфейса

Русский, English, Español, Français, العربية, हिन्दी, Português, Bahasa Indonesia, Türkçe, 简体中文. Переведены каталоги основного рабочего места, включая новые поля генетического отчёта и DOCX. Расширенная станция использует тот же выбор языка и существующий перевод её основных элементов. Для арабского включается RTL. Язык ответа модели по-прежнему выбирается отдельно.

Переводы интерфейса подготовлены с помощью модели и нуждаются в редакционной проверке носителями языка. Автотест проверяет наличие непустого перевода каждой строки во всех десяти каталогах. Клинический текст из сохранённого случая не переводится незаметно при смене языка интерфейса.

## Настоящий DOCX

Добавлена кнопка «Бланк DOCX» в карточке. Кнопка скачивания протокола в станции также отдаёт `.docx`. Эндпоинт `/api/export/docx` создаёт настоящий OOXML ZIP с Word document/styles/relationships и корректным MIME. Это не HTML, переименованный в `.doc`.

Синтетический бланк прошёл проверку ZIP/XML, отрисовку и визуальную проверку. Системная утилита macOS `textutil` прочитала из него кириллицу. При этом запуск самого Pages отдельно не проверялся.

## Обычные VCF

Больше не требуются нестандартные заголовки `doctor-opus-*`. Поддерживаются стандартные строки VCF, GT в произвольной позиции FORMAT, раздельные ALT, аннотации ANN/CSQ, Gene_Symbol/SNPEFF/VEP, качественные фильтры и присутствующие в файле сведения о значимости. Референсные генотипы не выдаются за альтернативные варианты. Ограничение сохранённой таблицы — 2000 альтернативных аллелей с явной отметкой неполного охвата.

Файл пользователя `Downloads/test.vcf` проверен локально, без сетевых вызовов: 902 записи, 114 альтернативных аллелей, 60 с аннотацией гена, сборка GRCh37/hg19, некорректных строк не обнаружено. Исходник в репозиторий не копировался.

Видны отдельные варианты и их аннотации, фильтр и страницы таблицы. Прочитанный файл больше не помечается непрочитанным из-за отсутствия критериев ACMG. Класс по всему VCF не присваивается. Общий INFO/AF и частота аллеля в образце не принимаются за популяционную частоту gnomAD. Координаты hg19 не отправляются в gnomAD GRCh38 без преобразования. Для аннотированных gnomAD-частот и явно переданных критериев используется детерминированная таблица; один PM2 не становится likely pathogenic. Встроенные старые dbSNP-описания помечены как аннотации исходника, а не новые подтверждённые классификации.

За основу разбора аннотаций взят подход geno-clinician; его контракт разделяет чтение VCF, частотные данные и классификацию. Старые GenomicsAI-Pro-заглушки, объявлявшие likely pathogenic по одному PM2 или имитировавшие отсутствие варианта в выборке, не переносились. Информация о статусах ClinVar сверена с [официальным описанием NCBI](https://www.ncbi.nlm.nih.gov/clinvar/docs/review_status/); исправлена ошибочная трактовка «no conflicts» как конфликта.

## Журнал терминала

При `npm run dev` или `npm start` сервер печатает строки `[Concilium]` с JSON:

- `run.started`, `run.planned`: идентификатор запуска, задача и число файлов.
- `model.started`: модель и провайдер.
- `model.responded`: HTTP-статус, причина завершения, токены, длительность и оценочная стоимость.
- `model.failed`: тип сетевого сбоя и длительность.
- `run.completed`: пригодность клинического результата, число полученных модельных ответов, прочитанных и неоценённых файлов, оценочная сумма.
- `run.failed`: тип необработанной ошибки без текста случая и стека с потенциальными данными.

Повторные попытки видны отдельными событиями. Завершённый HTTP-вызов и пригодный клинический результат не приравниваются друг к другу. Тарифная оценка не является банковским списанием или биллинг-квитанцией провайдера. Содержимое файлов, генотипы, вопросы, ФИО и ключи не включаются в эти события. Тест с маркером приватного текста проверяет отсутствие его в журнале.

## Итоговая проверка

157 автотестов прошли. В браузере подтверждены переведённые формы и помощник на испанском, а также арабский интерфейс с `dir=rtl`. Маршрут DOCX вернул HTTP 200, правильные MIME и Content-Disposition, ZIP-сигнатуру PK; macOS textutil прочитал синтетический документ. Ожидание события загрузки во встроенном браузере не сработало, поэтому подтверждение фактического сохранения через него не заявляется. Скачивание переведено на нативный HTTP attachment вместо короткоживущего blob-URL.

На синтетическом VCF живой сервер вернул статус файла `read`, таблицу варианта и завершённый черновик. В терминале появились события модели с HTTP 200, токенами, временем и оценочной стоимостью $0.005734. Реальный пользовательский VCF для этой сетевой пробы не использовался.
