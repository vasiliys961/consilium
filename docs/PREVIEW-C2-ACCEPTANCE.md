# Doctor Opus · P0/C2 · независимая приёмка Preview 3207

**Статус:** инженерная подготовка; реальный Mac и браузер ещё не проверены. Документ НЕ подтверждает клиническую точность ECGFounder, Radiology и консилиума.

## Границы безопасности
- Единственная папка для действий: `~/Documents/Consilium-Preview`. Исходную установку Codex и порт **3107** не трогать.
- Работа только с синтетическими данными. Реальные данные пациентов не вводить.
- Проверка загрузки страницы, сохранения, обновления браузера и экспорта **не требует** OpenRouter.
- **Не нажимать «Разобрать» при наличии рабочего API-ключа**, пока отдельно не разрешены тестовые платные вызовы и их бюджет. Действие может вызвать модель.
- `npm run dev` в Preview не использовать: он предназначен для другого порта. Только `npm run dev:preview`.
- При незакоммиченных изменениях команды обновления останавливаются без `reset` и без `stash`.

## Когда разработчик подтвердил CI и сказал «пора проверить 3207»

Остановить **только терминал, где запущен Preview** (нажать Ctrl+C, если он всё ещё работает). Порт 3107 оставляем как есть. Затем в отдельном терминале Mac:

```bash
cd ~/Documents/Consilium-Preview || exit 1
if [ "$(basename "$(pwd -P)")" != "Consilium-Preview" ]; then echo "Не та папка — ничего не изменено"; exit 1; fi
if [ -n "$(git status --porcelain)" ]; then echo "В Preview есть локальные изменения: переключение остановлено"; git status --short; exit 1; fi
git fetch origin || exit 1
git switch --detach origin/chatgpt/c2-preview-acceptance-20261115 || exit 1
npm ci || exit 1
npm run dev:preview
```

Открыть **http://127.0.0.1:3207/workspace**. Если порт занят, сначала проверить, какой процесс его держит; не переводить приложение на 3107. Ветка `main` и рабочее дерево Codex от этих команд не меняются.

## Бесплатная врачебная проверка в браузере

1. Убедиться, что загружается Preview 3207, а отдельно существующая страница 3107 остаётся без изменений.
2. В Preview открыть хранилище случаев паролем, если оно защищено. Создать новый **синтетический** случай. В контекст написать `QA-3207: синтетическая история без пациентов`, в поле вопроса — `QA-3207: что изменилось?`. Никакого AI-запроса не запускать.
3. Сохранить случай, обновить страницу браузера. Открыть тот же случай. Проверить: ввод и черновик вопроса сохранились; число разборов не увеличилось, клиническое заключение не появилось.
4. Добавить новое наблюдение `QA-3207: новые данные для обсуждения`, сохранить, снова обновить браузер и убедиться, что запись и порядок событий не утрачены.
5. Экспортировать случай в Markdown. Проверить наличие незавершённого вопроса и явную пометку **«не является заключением»**, но отсутствие выдуманного заключения. Файлы экспорта могут содержать введённый текст — хранить локально.
6. При необходимости завершить проверку, остановив только `npm run dev:preview` через Ctrl+C.

## Что уже проверено без API, что не проверено на Mac

Автоматические синтетические тесты покрывают: прерывание SSE до/после терминального результата; повреждённый JSON; сохранение и повторное открытие зашифрованного IndexedDB; восстановление несданного вопроса после потери соединения; повторное открытие после успешного ответа; ошибку записи в локальное хранилище; неповторение неподтверждённых диагнозов и привязку результатов ECGFounder/Radiology к SHA-256. Готовность полного клинического контура требует реального браузера и, **после отдельного решения о бюджете**, проверяемого вызова моделей.

Если после обновления возникает ошибка запуска — прислать только текст ошибки и состояние `git status -sb` из папки Preview, без файлов пациентов и без ключей.
