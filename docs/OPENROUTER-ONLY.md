# Провайдер нынешнего приложения · 13 ноября 2026

По указанию пользователя нынешнее приложение использует OpenRouter. Polza здесь отключена, включая резервный переход, чтение каталога цен и вспомогательные скрипты.

Область настройки — основной сервер и интеграционные копии, которые он запускает на портах 3110–3113. Самостоятельные исходные приложения на Desktop, их .env, ключи и прежние варианты работы не менялись.

- Общий шлюз отправляет запросы только OpenRouter, даже если в сохранённом .env есть ключ Polza.
- При ошибке или недостатке средств OpenRouter перехода на Polza нет.
- Запуск `npm run start/dev/build` включает scripts/openrouter-only.cjs. Для дочерних модулей lib/provider-runtime.ts маскирует ключи Polza и старые LLM-алиасы, передаёт OpenRouter и устанавливает тот же сетевой запрет в отдельном процессе.
- Встроенные протоколы используют OpenRouter при установленном флаге интеграции; при его отсутствии прежняя самостоятельная логика серверных адаптеров сохраняется. Интерфейс интеграционных копий предлагает OpenRouter.
- В радиологии выбран OpenRouter, сохранённый выбор Polza мигрирует на OpenRouter; серверный шлюз не принимает Polza в режиме нынешнего приложения. ЭКГ использует локальный ECGFounder и общий OpenRouter-шлюз для модельной интерпретации.
- В интегрированном RU-протоколе загрузка аудио, ранее отправлявшаяся Polza STT, направляется Gemini Flash через OpenRouter; исходный самостоятельный режим Polza STT не переписан. Фактическая стоимость берётся из usage.cost, если она передана; фиктивная длительность не рассчитывается из размера файла.
- Исторические записи расходов Polza не удалены. Наличие старого ключа или старой квитанции не означает, что Polza включена сейчас.

Проверка — только подставной транспорт и чтение состояния локальных серверов. Платные модельные запросы для проверки переключения не запускались.

Проверено после перезапуска: основной /api/status сообщает provider=openrouter и polzaEnabled=false; health радиологии, RU- и EN-протоколов сообщает openrouterOnly=true. Процессы перезапущены только после проверки, что их cwd находится внутри нынешнего workspace. Отдельные исходные процессы вне проекта не останавливали.

Основные тесты: 280/280; дополнительно прошли 4 проверки границы провайдера, включая сохранение прежней самостоятельной конфигурации протокола без флага интеграции. Собраны основной интерфейс, Radiology и обе версии протокола. Проверки не вызывали платные модели.


### Консилиум: состав и тариф Argon (13 ноября 2026)

Гипотезы — Gemini 4 Argon; обследования — GPT-6.1 Sol; критик и итог — Claude Opus 5.5; безопасность и избыточность — Claude Sonnet 5.5. Первые четыре мнения независимы, итог учитывает их ответы.

С 1 декабря 2026 перед консилиумом используется проверка каталога OpenRouter (кеш не более 6 часов). При подтверждённом росте входного или выходного тарифа Argon относительно $2/$10 за миллион токенов генератор гипотез автоматически переходит на Gemini 4 Hydrogen (`google/gemini-4-hydrogen`). Само наступление даты и недоступность каталога не считаются подтверждением подорожания. Политика вычисляется для каждого нового запуска, не меняя уже выполняющийся запрос. Выбор модели чтения изображений остаётся отдельным.

Проверки выполняются с подменёнными ответами, без платных запросов моделей.

13 ноября: по выбору врача Hydrogen заменяет ранее запланированный Gemini 3.1 Pro только в тарифном переключении генератора гипотез. Идентификатор проверен по https://openrouter.ai/google/gemini-4-hydrogen. Сейчас остаётся Argon; переход зависит от подтверждённого роста цены после даты проверки.

## Текущий выбор врача · 14 ноября 2026

Основная связка чтения изображений и итогового описания: Argon → Opus. После подтверждённого подорожания Argon с даты проверки 1 декабря — Flash 3.8 → Opus. Hydrogen больше не является резервной моделью и не предлагается в переключателе; прежний cookie Hydrogen не применяется. Синтез Opus сохраняется. Это решение заменяет предыдущие планы Pro/Hydrogen. Полное описание рентгенограммы сохраняется отдельно от краткого заключения и показывается раскрытым. Для ЭКГ сохраняется краткое заключение с подробным протоколом в раскрывающемся блоке.
