# W5 — контекстные подсказки врачу при неоднозначных клинических данных

**Дата:** 19.11.2026. **Статус:** изолированный Draft PR поверх PR #106. Только GitHub Actions; локальный Mac и платные модели не задействованы.

## Зачем

Ранее лекарственная безопасность правильно исключала неправильные или противоречивые значения, но врачу показывалось преимущественно «уточните». Теперь к существующему результату добавляются **структурированные, но неподтверждённые подсказки**: исходная запись, тип затруднения, ожидаемый *формат* и конкретный вопрос о проверке.

Примеры:
- `K+: 5.9 mg/dL` → возможная ошибка подписи единиц; сверить лабораторный бланк, **не** считать автоматически `5.9 mmol/L`.
- `eGFR: 25 mg/dL` → возможно перепутаны СКФ и концентрация креатинина; сверить наименование показателя.
- `QTc: 520 s` → возможно перепутаны секунды и миллисекунды; сверить ЭКГ, **не** превращать автоматически в `520 ms`.
- `Age: 75 months` → проверить единицы и возраст по дате рождения; не считать `75 years`.
- `СКФ: 25` и `СКФ: 78` → проверить дату и метод; не выбирать значение за врача.
- `Active bleeding: pending` → уточнить текущий статус, не подменять «неизвестно» на «нет».

## Контракт

`extractMedicationSafetyContext` по-прежнему возвращает только подтверждённые значения в `context`, с диагностическими `issues`; новое поле `hints` содержит **исключительно подсказки**, маркированные `requires_physician_confirmation`. Подсказки не используются `checkMedicationRegimen` и не записываются поверх фактов случая.

При генерации клинического отчёта подсказки присоединяются **после** ответа модели и видны врачу отдельно от назначения и в текстовом представлении отчёта. English-подписи предусмотрены; остальные языки используют предусмотренный интерфейсом fallback, не платный машинный перевод.

## Проверка без браузера

`npm test`, `npm run typecheck`, `npm run build` в GitHub Actions; отдельные синтетические тесты для неверных единиц, противоречий, старых измерений, отрицательных контролей и неизменности исходных фактов. Никаких внешних API.

**Границы:** это не автоматическое решение о дозе, лечении или лабораторном результате; нет реального тестирования клинических показаний, валидации врачом или браузерного теста Preview 3207. Изменения требуют осмысленного объединения с PR #106; PR #104 независим.
