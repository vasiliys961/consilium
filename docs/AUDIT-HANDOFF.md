# Исходники для аудита · 15 ноября 2026

Это снимок нынешнего интегрированного приложения Doctor Opus, включая локальные копии модулей в integrations/. Исходные самостоятельные приложения вне workspace не входят и не изменялись.

## Границы публикации

Включаются исходники, промпты, тесты, lock-файлы, конфигурации без секретов, документация и .env.example. Исключаются .env и локальные ключи, node_modules, сборки, веса моделей, кеши, загруженные книги, материалы пациентов и каталог artifacts с результатами тестовых прогонов. Веса и зависимости устанавливаются отдельно по существующим инструкциям.

## Без развёртывания

В корневом vercel.json и integrations/radiology/web/vercel.json установлен git.deploymentEnabled=false. Репозиторий для аудита не следует подключать к Vercel. Эти настройки запрещают штатные Git-деплои; они не заменяют проверку внешних GitHub Actions и существующих интеграций выбранного репозитория до отправки. Команды deploy не выполнялись.

## Проверка кода

Начать с README.md, AGENTS.md, docs/ROADMAP.md и docs/IMAGE-ANALYSIS-2026-11-14.md. Приложение использует только OpenRouter; см. scripts/openrouter-only.cjs и lib/gateway.ts. Результаты ИИ являются черновиками для проверки врачом. Функциональные тесты не подтверждают клиническую точность.
