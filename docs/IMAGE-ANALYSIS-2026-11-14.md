# Анализ изображений: новая рабочая схема

Решение владельца 14 ноября 2026: приоритет качества; Argon сохраняется после изменения тарифа. Все модельные вызовы нынешнего приложения — через OpenRouter. Отдельные исходные приложения вне workspace не изменялись.

## КТ / МР

В радиологической станции Flash 3.8 просматривает весь выбранный объём пакетами до четырёх кадров. Существующие декодеры, окна, локальные детекторы, ограничения памяти, подготовка копий и журнал фактического охвата сохранены.

Argon получает JSON наблюдений, факты выполненных детекторов, клинический контекст и подборку до 16 изображений: приоритетные для врача срезы, значимые участки с соседями и распределённые контрольные срезы. Контрольные кадры добавляются и при пустом отборе Flash. Ограничение размера передачи сохраняется; фактические номера кадров приведены в результате. Отмеченные срезы вне подборки не считаются перепроверенными Argon.

Один основной вызов Argon формирует полное описание и отдельное заключение. Opus вызывается при существенном неразрешённом расхождении либо кнопкой врача. Он получает изображения и клинический контекст, без заключения Argon и списка диагнозов Flash. Основное заключение и независимые наблюдения показаны отдельно: автоматический выбор победителя не выполняется. При сбое Opus протокол Argon остаётся доступен.

Legacy URL `/api/ai/complete-volume-opus` сохранён для совместимости, но основной маршрут вызывает `analyzeVolumeWithArgon`. Старый текстовый синтезатор оставлен для совместимости внутренних исследовательских функций и их тестов; основной интерфейс на него не направляется.

## Единичные изображения

В радиологической станции PNG/JPEG и выбранные рентгеновские проекции читаются непосредственно Argon, с фактически выполненными детекторами. Обязательная пара Flash→Opus заменена одним основным читателем. Opus получает оригинальные проверенные копии независимо при существенном конфликте либо по кнопке.

В общем разборе случая / расширенной станции визуальный читатель закреплён за Argon; при существенном конфликте или явном запросе Opus получает тот же исходный кадр без вывода Argon. Его результат и стоимость отделены от основного чтения. Для синтеза клинического ответа по прочитанным изображениям используется Argon вместо обязательного текстового Opus. Консилиум остаётся отдельной явно включаемой функцией со своими ролями.

## Повторы, цена и сохранение

В радиологической станции основной ответ сохраняется в ограниченном серверном кеше на 10 минут (до двух исследований). По кнопке второго мнения в этот период Argon не запускается повторно. По истечении кеша сервер не начинает его автоматически: требуется явно запустить новый разбор. Готовый результат сохраняется в браузерном интерфейсе; эти десять минут относятся к серверному повторному использованию, а не сроку хранения врачебного случая.

В расчёте стоимости разделены обзор Flash, основной Argon и условный Opus. Это оценка по токенам и тарифам, не окончательный счёт провайдера. Повышение цены не меняет основной медицинский читатель. Для вспомогательных задач остаётся ручной выбор модели; радиологические визуальные вызовы закреплены за Argon; профильные исключения для остальных изображений перечислены ниже.

## Проверка

Проверяются: передача исходных изображений; отсутствие заключения Argon в независимом запросе Opus; отсутствие обязательного Opus без конфликта; повторное использование основного протокола; сохранение протокола при сбое второго мнения; связь с исходными срезами; контрольная подборка при отсутствии находок; цена и политика после изменения тарифов; совместимость прежних форматов и сохранения.

Функциональные проверки с искусственными ответами не являются проверкой клинической точности. Новых платных модельных тестов при внедрении не запускалось. Преимущество всей схемы на КТ/МР ещё требует отдельного сравнения.

## Дополнение: другие медицинские изображения

Последующее решение владельца в этом чате: выбирать первый читатель по задаче; при существенном сомнении передавать ДРУГОЙ модели исходное изображение и JSON первого ответа. Для этих профилей второе мнение помечается «Проверка с учётом первого ответа». Оно не называется слепым независимым чтением. Согласованная независимая перепроверка радиологии и ЭКГ сохранена.

Рабочие маршруты общего разбора случая и расширенной станции:

| Профиль | Первый читатель | Второй при сомнении / запросе |
|---|---|---|
| УЗИ | GPT-6.1 Terra | Claude Opus 5.5 |
| Микроскопия крови | GPT-6.1 Terra | Claude Opus 5.5 |
| Гистология | Gemini 4 Argon | Claude Opus 5.5 |
| Дерматоскопия, рана | Gemini 4 Argon | Claude Opus 5.5 |
| Эндоскопия | Gemini 4 Argon | Claude Opus 5.5 |
| Глазное дно | Claude Opus 5.5 | Gemini 4 Argon |
| Маммография | Gemini 4 Argon | Claude Opus 5.5 |
| Неопределённый профиль | Gemini 4 Argon | Claude Opus 5.5 |

Это предварительные инженерные назначения, не доказанное клиническое превосходство. Для профилей со слабым прямым сравнением сохранён Argon вместо произвольной замены. Нужный профиль выбирается врачом в существующем селекторе; для произвольного файла без известного профиля сохраняется общий маршрут. Добавлен профиль «Микроскопия крови». Оригинальные самостоятельные приложения не изменялись.

Основания на 14 ноября 2026:
- Ultralytics UL37: Terra сильнее на ограниченных задачах поиска объектов в тиреоидном УЗИ и микроскопии клеток крови; Argon — один из лучших на Kvasir-SEG. Это задачи локализации, по десять изображений каждого набора, а не испытание полной диагностики или протокола: https://www.ultralytics.com/blog/gpt-6-1-terra-auto-annotation .
- Mitosis Bench: Argon 32.4%, Opus 28.6% pass@1 на строгом поиске всех митозов; агент с инструментами, небольшой отдельный набор, а не оценка всей гистопатологии: https://dylantirandaz.com/projects.html/mitosisbench/ .
- Для глазного дна результаты поиска очагов у всех моделей низкие, Opus — один из близких лидеров прежнего сравнения. Это слабый сигнал для пробного выбора, не основание утверждать диагностическую надёжность. Новый Carbon выше на 0.001 mAP в DDR, что не обосновывает замену всей схемы: https://www.ultralytics.com/blog/gemini-4-carbon-auto-annotation .
- Официально подтверждены изображения, Chat Completions и структурированные ответы Terra: https://developers.openai.com/api/docs/models/gpt-6.1-terra ; в приложении используется исключительно OpenRouter: https://openrouter.ai/openai/gpt-6.1-terra .

В коде: `packages/medical-images/routing.ts`. Во втором запросе JSON рассматривается как непроверенные данные; нет автоматического выбора победителя. Сохраняются исходный ответ, второе мнение, выбранные модели, метод проверки и отдельный расход. Смена политики инвалидирует прежний кеш визуального чтения только для следующего явно запрошенного разбора; история случая остаётся.

Итоговая функциональная проверка: 303 теста основного приложения и 66 профильных тестов радиологии прошли; после последних правок повторены 17 тестов маршрутизации и чтения. Обе production-сборки завершены. В Chrome проверены выбор профиля и модели без запросов к провайдеру; в радиологическом интерфейсе на искусственных ответах проверены второе мнение, сохранение правки врача и передача обоих результатов в случай. Ошибок страницы не обнаружено. Это проверка работы приложения, не клинической точности моделей.
